# HexaCube

A VST3 drum sampler plugin reproducing the sound of a vintage analog drum machine — the Simmons SDS-8 — with 16 instruments, 6 velocity layers, and 4 round-robin variations per instrument (384 samples total).

Instruments are organized into two voice banks: the original factory sounds and a complementary voXager bank recorded and processed to match the character of the originals.

Built with JUCE and CMake, targeting Windows (VST3). Cross-compiled from Linux using MinGW-w64.

## Status

Early development. Core engine and plugin UI are functional.
